# OrbNook downloads

This public repository contains installer releases and their checksums. OrbNook application source is maintained separately in private repositories.

## Current status

The 0.2.1 release candidate is for validation, not a declaration that customer sales are open. Download the `.msi` release asset; GitHub's automatic source archives contain repository documentation, not the app.

The direct edition includes the Windows x64 app and its .NET desktop runtime in one MSI. Open OrbNook from Start after installation. Website licenses use Dodo Payments activation. A valid purchase/license is required; no key or merchant credential is included here.

Windows notification mirroring is not included in this direct-download edition. It is reserved for the planned Microsoft Store edition, coming later.

The candidate is unsigned. Windows may apply security or reputation checks. Do not bypass security warnings as part of these instructions.

Installer database/payload checks and this PC's per-user installation, upgrade, repair and uninstall checks passed. Clean-PC execution and genuine purchase/activation/refund verification remain pending. Gumroad activation is not hosted yet; this candidate must not be delivered to Gumroad buyers as a working Gumroad release.
